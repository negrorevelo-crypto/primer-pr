CHELART CONSTRUCTION — SITIO Y DISEÑO PARA PLESK

Paquete actualizado con las imágenes corregidas de Chelart. Incluye public/ y el código PHP auxiliar de config/ necesario para las páginas.

No incluye base de datos, sql/schema.sql, credenciales ni archivos secretos. Extrae public/ y config/ al mismo nivel dentro de la carpeta del dominio y configura Document root hacia public/. Conserva cualquier config/plesk-secrets.php privado que ya exista; no viene incluido ni se sobrescribe.

Este ZIP por sí solo no modifica MariaDB. Para guardar cotizaciones, el hosting debe tener la base de datos existente y config/plesk-secrets.php correctamente configurados.
